01신중하게

아이디(@사용자 이름)

예쁜 이름보다 부를 수 있는 이름이 이깁니다.

경로프로필 → 프로필 편집 → 사용자 이름

바꿀 값

  • 뜻 모를 영어 조합(abc_1024_x)은 버립니다.
  • 검색될 이름 + 브랜드명으로 갑니다. 짧을수록 좋고, 한글 발음 기준 2~4글자 정도가 가장 잘 외워집니다.
  • 예시 — 09.oppa(영구오빠), __songshop(송샵)

왜

손님이 나중에 다시 찾아올 때 기억해 내는 건 계정 이름입니다. 명함·카톡·영수증에 적어 줬을 때 손으로 쳐서 바로 나오는지가 기준입니다.

아이디는 자주 못 바꿉니다

바꾸는 순간 예전 아이디로 연결해 둔 링크, 태그, 검색 결과가 끊깁니다.

→ 정말 바꿀 거면 한 번에 끝낼 이름을 정하고 바꾸세요.

02오늘 10분

이름 칸
— 여기가 검색의 전부입니다

대부분의 원장님이 여기를 이름만 적거나 아예 비워 둡니다.

경로프로필 편집 → 이름

바꿀 값

공식

지역명 + 시술명 + 브랜드명 + 역할

예시 1잠실눈썹문신 강릉눈썹문신 | songshop 송샵 | 대표원장 송민성
예시 2영구오빠 | 눈썹문신 반영구 창업 · 마케팅 코치

왜

인스타 검색은 아이디와 이름 칸의 글자를 읽습니다. 자기소개(bio)에 아무리 잘 써도 검색에는 거의 안 잡힙니다.

✕OO 뷰티 만 써두면 → "잠실 눈썹문신" 검색에 안 나옵니다.
○지역명을 꼭 넣으세요. 반영구는 동네 장사입니다. 지역이 빠지면 검색 유입이 통째로 사라집니다.
○2호점이 있으면 두 지역을 다 적습니다.
03오늘 10분

프로필 사진
— 얼굴이 신뢰를 만듭니다

로고는 브랜드를 알리지만, 얼굴은 신뢰를 만듭니다.

경로프로필 편집 → 사진 변경

바꿀 값

  • 기본 아바타, 로고만 있는 이미지 → 원장님 얼굴 사진
  • 깔끔한 단색 배경(흰색·그린 등)에 상반신, 정면, 웃는 표정
  • 프로필은 아주 작은 원으로 보입니다. 얼굴이 원 안에 꽉 차게 잘라 주세요.

왜

반영구는 손끝에 얼굴을 맡기는 시술입니다. 시술자가 누구인지 안 보이면 예약 버튼을 못 누릅니다.

04업종 표시

카테고리

프로페셔널 계정에서만 보입니다. 개인 계정이면 먼저 전환하세요.

경로프로필 편집 → 프로필 정보 → 카테고리

바꿀 값

건강/뷰티 또는 그에 가까운 업종

왜

이름 바로 아래 회색 글씨로 붙어서, 이 계정이 가게 계정이라는 걸 0.5초 만에 알려 줍니다.

  • 다른 계정(두피·속눈썹 등)이 있으면 두피계정 : @scalp_by_song 처럼 한 줄로 연결해 둡니다.

06이번 주

링크
— 예약으로 가는 유일한 문

클릭 한 번에 상담창이 열리는 게 가장 좋습니다.

경로프로필 편집 → 링크 → 외부 링크 추가

바꿀 값

  • 예약·상담으로 바로 떨어지는 주소 1개
  • 예시 — 카카오 채널 상담(pf.kakao.com/...), 인포크링크 같은 링크 모음(link.inpock.co.kr/...)
  • 자기소개 마지막 줄에서 👇 로 링크를 가리켜 주세요. 링크가 있는데 아무도 안 누르는 이유는 가리키지 않아서입니다.

왜

인스타 안에서는 예약을 받을 수 없습니다. 링크가 유일한 출구인데, 여기서 한 번 더 고르게 만들면(홈페이지 → 메뉴 → 예약) 사람이 샙니다.

자기소개 링크는 여러 개(최대 5개) 넣을 수 있지만, 예약률만 보면 1개가 가장 셉니다. 선택지가 늘면 결정이 늦어집니다.

07이번 주

고정 게시물 3개
— 들어오자마자 보이는 첫 줄

최신 게시물이 뭐든 이 3칸은 고정입니다.

경로해당 게시물 → 오른쪽 위 ⋯ → 내 프로필에 고정
칸넣을 것실제 예시
①대표 시술 1내가 제일 잘하는 것상담부터 시술까지 어떻게 진행될까요?
②브랜딩 1내가 누구인지원장 소개 / 샵 소개 릴스
③후기·자료 1결과를 증명하는 것탈각 후 모음 (시술 사례 모아 둔 게시물)

왜

프로필에 들어오면 사진 아래 첫 줄 3칸이 가장 먼저 보입니다. 여기에 "무엇을 잘하고 / 누구이고 / 결과가 어떤지"를 미리 깔아 두는 겁니다.

3개 이상, 고객이 예약 전에 묻는 순서대로 배치합니다.

경로스토리 올리기 → 하이라이트에 추가 (또는 프로필에서 + → 새로 만들기)

그 밖다른 시술이 있으면 따로 — 속눈썹펌 등

왜

하이라이트는 FAQ 창구입니다. 여기가 비어 있으면 그 질문이 전부 DM으로 들어와서 원장님 시간을 먹습니다. 한 번 만들어 두면 24시간 대신 답해 줍니다.

커버 이미지는 톤을 맞추세요(같은 배경색 + 글씨 하나). 제목은 5글자 이내로 짧게 — 길면 잘립니다.

09탭 정리

릴스 · 리믹스 · 태그됨

원장님은 격자 탭만 보지만, 손님은 탭을 눌러 봅니다.

경로프로필 사진 아래 탭 줄 (격자 / 릴스 / 리믹스 / 태그됨)
탭체크할 것
릴스영상이 여기 다 모입니다. 썸네일 글씨가 잘리진 않았는지 쭉 내려 보세요.
리믹스남이 내 영상에 붙인 리믹스가 쌓입니다. 원하지 않는 게 있으면 해당 영상에서 리믹스 허용을 끄세요.
태그됨아무나 나를 태그하면 여기 들어옵니다. 설정 → 태그 및 멘션 → 수동 승인으로 바꿔 두세요.경쟁 샵 홍보나 광고 계정 태그가 내 프로필에 걸려 있는 경우가 생각보다 많습니다.

왜

관리 안 된 탭 하나가 "여기 운영 안 하는 곳인가?"를 만듭니다.

Q자주 나오는 질문

자주 나오는 질문

눌러서 펼쳐 보세요.

Q아이디를 바꾸면 팔로워가 날아가나요?+

아니요, 팔로워는 그대로입니다. 다만 예전 아이디로 걸어 둔 링크와 태그가 끊깁니다. 명함·네이버 플레이스·카톡 채널에 적어 둔 주소도 같이 고쳐야 합니다.

Q이름 칸에 키워드를 너무 많이 넣어도 되나요?+

글자 수 제한이 있어서(현재 30자) 어차피 많이 못 넣습니다. 지역 2개 + 시술명 + 브랜드명 정도가 한계이자 적정선입니다. 읽었을 때 문장이 아니라 나열이어도 괜찮습니다.

Q얼굴을 꼭 걸어야 하나요?+

가장 강하지만 필수는 아닙니다. 못 거는 사정이면 시술 중인 손 클로즈업이나 샵 간판을 쓰세요. 기본 아바타와 의미 없는 이미지만 피하면 됩니다.

Q고정 게시물을 바꾸면 조회수가 떨어지나요?+

고정 자체는 노출에 영향이 없습니다. 다만 고정하면 게시 날짜 순서와 상관없이 맨 앞에 서니까, 오래된 영상이라도 반응이 좋았던 것을 올려 두는 게 유리합니다.

Q하이라이트 커버를 예쁘게 만들 시간이 없습니다+

커버보다 제목과 순서가 먼저입니다. 일단 스토리 캡처 그대로 만들어 두고, 커버는 나중에 한꺼번에 교체하세요. 비어 있는 것보다 투박한 게 낫습니다.
